# Networking_Labs_-Uni-
CST1530 Computer Networks labs covering OSI/TCP-IP models, subnetting, CIDR, VLSM, Ethernet design, packet analysis, and Cisco IOS configuration in a small internetwork
CST1530 COMPUTER NETWORKS - LAB WORK

Overview:
This repository contains my lab work for CST1530 Computer Networks. 
The labs focus on foundational networking concepts, neteork design, IP addressing and basic configuration using Cisco tools (Packet Tracer)

Topics Covered:
- OSI and TCP/IP Network Models
- LAN, WAN, and basic networking concepts
- Application, Transport, Network, Data link, and Physical layers
- Ethernet technology and operation
- Network design and cabling fundementals
- IP addressing and subnetting
- CIDR and VLSM
- Static and dynamic routing
- Basic networking security concepts
- Cisco IOS router and switch configuration
- Packet analysis and traffic tracing

  Tools Used:
  - Cisco Packet Tracer
  - Wiresark
  - CLI
 
  The files are uploaded on a weekly basis hence structured also like that.
  All files and designs were completed as a part of university coursework to study and demostrate practical networking skills.
